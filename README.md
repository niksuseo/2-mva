## Лабораторная работа № 1. Контейнеризация (Docker)

**Цель:** контейнеризация веб-приложения и запуск его совместно с PostgreSQL.

### Используемые технологии
- Python и Flask — веб-приложение
- PostgreSQL — база данных
- Docker — контейнеризация
- Docker Compose — запуск и взаимодействие контейнеров

### Запуск

Установить Docker и выполнить из папки `laba1`:

```bash
docker build -t architecture-lab1 .
docker compose up -d
```

Приложение: http://localhost:8080

История запросов: http://localhost:8080/api/v1/get

Каждый запрос к `/api/v1/get` добавляет запись в PostgreSQL и возвращает историю запросов.
